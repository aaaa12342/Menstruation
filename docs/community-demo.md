# 互助社区演示操作

1. 打开“互助”，点击“匿名提问”，输入标题和描述，勾选本机保存说明，提交审核。
2. 返回“互助 → 我的帖子”，可以立即看到帖子及“待审核”状态。此时帖子不会出现在广场。
3. 点击“进入本机审核与回复演示台”，通过帖子。回到“全校广场”可看到新帖。
4. 打开已通过的帖子，提交一条回复。回复先进入待审核队列；在演示台通过后，帖子作者的“回复消息”会出现未读提醒。
5. 也可在演示台对自己的已通过帖子点击“发送演示回复”，直接验证未读提示。打开该帖子后，未读状态会清除。
6. 在“隐私与使用说明”中可删除当前设备保存的全部社区数据。

演示版使用微信小程序本地缓存。审核台不具备管理员身份验证；不同设备之间不会同步帖子或消息。正式运营需接入服务端存储、权限控制、内容审核、申诉举报、未成年人保护和完整隐私政策。
